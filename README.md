# curiosity-daily

## Rules

1. **Date folders** — all content organized under `YYYY-MM-DD/`
2. **Standalone long articles** — one `.md` file per substantive article
3. **Merged links & tools** — scattered links, small tools, one-liner notes go into the day's `_links-and-tools.md`
4. **Clean filenames** — kebab-case, readable at a glance
5. **`tools.md`** — curated running list of interesting tools and repos, updated as new ones are found
